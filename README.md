# DesktopTodo · 桌面待办

A tiny transparent todo card that lives on your macOS wallpaper — always visible, never in the way.
一个常驻 macOS 桌面的透明待办卡片：一直在，但不挡事。

- 透明底（毛玻璃／纯文字两种），浮在壁纸之上、所有窗口之下
- ⌥ Space 全局热键：随手记；在别的 App 里选中文字按它，那句话直接进待办
- 每天 0 点自动重置，统计连续完成天数
- 单个 Swift 文件写成，无 Xcode 工程，无第三方依赖，数据就是一个本地 JSON

---

## 两种装法

### A. 直接用现成的（不用装开发工具）

文件夹里的 `DesktopTodo.app` 是 universal 版本（Apple 芯片 / Intel 都能跑）：

1. 把它拖进「应用程序」文件夹
2. 双击打开。若系统提示「无法验证开发者」：
   **系统设置 → 隐私与安全性 → 仍要打开**（或右键 App 选「打开」）
3. 菜单栏右侧出现 ✓ 图标，卡片已经在桌面右上角了

### B. 自己编译（改过源码时用）

需要 Xcode 命令行工具（没有就先跑 `xcode-select --install`）：

```bash
cd DesktopTodo
./install.sh
```

脚本会自动挑一个和本机 `swiftc` 版本匹配的 SDK、按本机架构编译、打包签名、装到 `/Applications`，并问你要不要开机自启。
不想编译直接装现成的 App 也行，跳过这一步即可。

## 用法

| 操作 | 怎么做 |
| --- | --- |
| 打勾 | 点圆圈或点文字；完成的变灰、划掉、自动沉底 |
| 加任务 | 点卡片底部输入框打字回车，或任何界面按 ⌥ Space |
| 收录选中文字 | 在别的 App 里选中一段，按 ⌥ Space，直接进待办 |
| 删任务 | 鼠标移到该行，右侧出现 × |
| 循环任务 | 移到该行点 ↻（亮着＝每天重复；关掉则完成第二天不再出现） |
| 移动 | 直接拖卡片，定好位可右键锁定 |

**⌥ Space 收录选中文字**需要「辅助功能」权限：菜单栏 ✓ → 设置面板 → 点「开启」→ 系统弹窗里勾上 DesktopTodo → **重启 App** 生效。没授权也能用，只是要自己打字。

## 设置入口

菜单栏右侧的 **✓ 图标**：

- 左键 → 设置面板：毛玻璃底／纯透明、不透明度、层级、锁定、鼠标穿透、开机启动、热键说明
- 右键 → 快捷菜单：显示隐藏、锁定、鼠标穿透、清除已完成、退出

在卡片上点右键也有常用菜单。

## 数据

`~/Library/Application Support/DesktopTodo/data.json` —— 纯文本，可直接看、可备份。
每天 0 点重置一次：勾掉的一次性任务归档消失，标了每天重复的取消勾选、第二天重现。

## 常见问题

**提示「无法验证开发者」** — 本地 ad-hoc 签名，没有 Apple 公证。系统设置 → 隐私与安全性 → 仍要打开。

**⌥ Space 没反应** — 检查有没有别的软件占了 Option+Space；或者 App 没在运行（菜单栏应有 ✓ 图标）。

**收录选中文字没反应** — 辅助功能权限没给，或者那个 App 不支持读取选中文本（部分应用会拿不到，此时会退化成唤起输入框自己打字）。

**全屏应用里看不到卡片** — 它活在桌面层，全屏窗口会盖住它。设置面板里把「层级」切成「始终置顶」可以在全屏时也看到。
